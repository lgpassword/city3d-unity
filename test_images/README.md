# 测试图片说明

## 如何使用本地算法生成3D模型

### 步骤1：准备图片
将任意图片放入此目录，推荐：
- 风景照片（山脉、建筑）
- 人物肖像
- Logo/图标
- 艺术作品

### 步骤2：在应用中选择算法

**1. HeightMap（高度图）- 推荐用于照片**
- 原理：像素亮度 → 高度值
- 效果：浮雕/地形效果
- 适合：任何图片

**2. Relief（浮雕）- 推荐用于艺术效果**
- 原理：增强对比度的高度图
- 效果：戏剧性的立体浮雕
- 适合：需要强烈立体感的场景

**3. Voxel（体素）- 推荐用于像素风**
- 原理：每个像素变成立方体
- 效果：Minecraft风格
- 适合：像素艺术、复古风格

**4. Contour Extrusion（轮廓挤出）- 推荐用于线稿**
- 原理：边缘检测 + 挤出
- 效果：线条立体化
- 适合：Logo、图标、线稿

### 步骤3：调整参数

**分辨率（Resolution）**
- 32：快速预览
- 64-128：平衡质量和速度（推荐）
- 256：高质量（较慢）

**最大高度（Max Height）**
- 0.1-0.5：平缓效果
- 1.0：标准（推荐）
- 2.0-3.0：夸张效果

**对比度增强（Contrast Boost）**
- 0.5-1.0：柔和
- 1.5：标准（推荐）
- 2.0-3.0：强烈

**平滑度（Smoothness）**
- 0：保留所有细节
- 2-5：平滑噪点（推荐）
- 10：非常平滑

**反转（Invert）**
- 关闭：亮 = 高，暗 = 低
- 开启：暗 = 高，亮 = 低

### 步骤4：生成并导出

1. 点击"✨ 生成3D模型"
2. 在右侧3D预览中查看效果
3. 选择导出格式（OBJ推荐）
4. 点击"💾 导出到文件"
5. 在Blender/3ds Max中打开编辑

## 算法对比

| 算法 | 速度 | 质量 | 适用场景 |
|------|------|------|----------|
| HeightMap | ⚡⚡⚡ | ⭐⭐⭐ | 通用照片 |
| Relief | ⚡⚡ | ⭐⭐⭐⭐ | 艺术浮雕 |
| Voxel | ⚡⚡⚡ | ⭐⭐ | 像素风格 |
| Contour | ⚡⚡ | ⭐⭐⭐ | 线稿Logo |

## 示例效果

### 风景照片 + HeightMap
```
输入：山脉照片
参数：分辨率128，高度1.0，平滑5
输出：立体地形模型
```

### 人物肖像 + Relief
```
输入：人脸照片
参数：分辨率256，高度1.5，对比度2.0
输出：浮雕肖像
```

### Logo + Contour Extrusion
```
输入：黑白Logo
参数：分辨率64，高度0.5
输出：立体Logo
```

## 性能参考

| 分辨率 | 顶点数 | 生成时间 |
|--------|--------|----------|
| 32 | ~1K | <100ms |
| 64 | ~4K | ~200ms |
| 128 | ~16K | ~500ms |
| 256 | ~65K | ~2s |

## 导出格式说明

- **OBJ**：通用格式，Blender/Maya/3ds Max都支持（推荐）
- **STL**：3D打印专用格式
- **glTF**：Web 3D标准格式
- **FBX**：游戏引擎和专业软件格式
